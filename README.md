# Pharmalink

Application web de recherche, comparaison et livraison de médicaments à Lomé (Niveau 1).
Site statique : un seul fichier `index.html`, aucune installation requise.

## Test en local
Double-cliquer sur `index.html`.

## Déploiement
Push sur GitHub, puis importer le dépôt sur vercel.com (Framework : Other, sans build).
